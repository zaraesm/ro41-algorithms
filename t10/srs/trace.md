# Практическое задание №10 (Сортировки и бинарный поиск)

## Задание 1. Сортировка выбором
Исходный массив: $a = \{5, 2, 9, 1, 7\}$

| Проход ($i$) | Индекс минимума | Массив после обмена | Число сравнений |
| :--- | :--- | :--- | :--- |
| 0 | 3 (значение 1) | `{1, 2, 9, 5, 7}` | 4 |
| 1 | 1 (значение 2) | `{1, 2, 9, 5, 7}` | 3 |
| 2 | 3 (значение 5) | `{1, 2, 5, 9, 7}` | 2 |
| 3 | 4 (значение 7) | `{1, 2, 5, 7, 9}` | 1 |

* **Общее число сравнений:** $4 + 3 + 2 + 1 = 10$.

## Задание 2. Сортировка вставками
Исходный массив: $a = \{4, 3, 2, 1\}$

| Шаг ($i$) | `key` | Число сдвигов | Массив после вставки |
| :--- | :--- | :--- | :--- |
| 1 | 3 | 1 | `{3, 4, 2, 1}` |
| 2 | 2 | 2 | `{2, 3, 4, 1}` |
| 3 | 1 | 3 | `{1, 2, 3, 4}` |

* **Сколько всего сдвигов?** 6 сдвигов ($1 + 2 + 3$).
* **Сравнения на отсортированном массиве из 4 элементов:** Алгоритм выполнит **3 сравнения** (по одному на каждый элемент, начиная со второго).

## Задание 3. Бинарный поиск
Массив: `{1, 3, 5, 7, 9, 11, 13}`

### А. Поиск $x = 7$
* **Шаг 1:** `lo = 0`, `hi = 6`, `mid = 3`, `a[3] = 7`. Решение: найдено (индекс 3).

### Б. Поиск $x = 6$
* **Шаг 1:** `lo = 0`, `hi = 6`, `mid = 3`, `a[3] = 7`. Решение: $6 < 7$, `hi = 2`.
* **Шаг 2:** `lo = 0`, `hi = 2`, `mid = 1`, `a[1] = 3`. Решение: $6 > 3$, `lo = 2`.
* **Шаг 3:** `lo = 2`, `hi = 2`, `mid = 2`, `a[2] = 5`. Решение: $6 > 5$, `lo = 3`.
* **Чем закончится поиск:** Условие `lo <= hi` нарушено (`3 <= 2` — ложь), элемент не найден.
* **Что вернёт `LowerBound(6)`:** Индекс **3** (первый элемент, который $\ge 6$, это число `7`).
